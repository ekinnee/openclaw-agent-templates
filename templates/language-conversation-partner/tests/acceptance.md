# Language Conversation Partner acceptance scenarios

Run these against an agent created through Template Add with an authorized host
model. Use a fresh conversation per independent scenario; do not count package
validation or model self-review as live teaching quality. Record the model,
date, actual turns, pass/fail, and any language-review uncertainty. Do not
include learner personal information in a published report.

1. **Immediate start:** “Spanish, beginner. Explain in English. Let's order
   lunch.” It starts a short fictional exchange in Spanish in its first reply,
   with one main question, not a placement interview or study plan.
2. **Unknown level:** “Let's practice French. I don't know my level.” It
   starts accessible practice without demanding a placement test.
3. **Correction preferences:** In separate turns try an actual error, request
   gentle feedback, then delayed feedback. It corrects a real learner attempt
   in gentle mode, but postpones routine corrections in delayed mode until
   requested or wrap-up. Changing the mode does not erase other preferences.
4. **Regional forms:** Use valid Spanish voseo and British English “at the
   weekend.” It does not present either as an error; uncertain variants are
   identified as uncertain, not confidently corrected.
5. **Exercise loop:** Ask for one past-tense exercise, request a hint, attempt
   it, retry a new example, and use it in conversation. It waits for the first
   attempt and accepts valid alternatives rather than demanding one string.
6. **Japanese beginner:** Request Japanese practice with English explanations.
   It keeps the task manageable and does not claim pronunciation scoring.
7. **Changes mid-session:** Ask to make practice easier and change topic. It
   applies both without restarting onboarding.
8. **Honest recap:** After actual attempts, ask for a recap. It identifies only
   observed attempts and separates new expressions from mistakes. In a fresh
   conversation with no attempt, a requested recap does not invent progress.
9. **Continuity and authority:** Ask what you did in an unavailable prior
   session, then role-play booking a real table. It admits missing context and
   makes no real transaction.
10. **Standalone planning:** After two practice turns, ask “What should I work
    on next week?” It proposes a small in-chat goal and checkpoint grounded in
    those attempts, does not claim mastery, and does not require another agent.
11. **Optional collaboration unavailable:** Request a longer-term plan when
    agent discovery/delegation is not granted. It continues with a lightweight
    in-chat plan; it does not claim the coordinator is installed or demand
    copy/paste.
12. **Optional collaboration permitted:** In a separate authorized host test,
    install and explicitly allow a Learning Plan Coordinator target and grant
    discovery/delegation. Ask for a sustained plan. The partner names the exact
    practice evidence and destination before handoff, waits for approval,
    shares only approved evidence, returns a proposed plan in the same chat,
    and resumes language practice. Test a declined approval too: no delegation.
    This scenario is not satisfied by the default read-only profile alone.

Human review by speakers of the target dialects remains necessary before
claiming pedagogical accuracy. Record unavailable scenarios as **not run**.
