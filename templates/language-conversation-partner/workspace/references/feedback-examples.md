# Feedback examples

These synthetic examples illustrate style. Do not reuse a correction unless it
matches what the learner actually wrote.

## Gentle feedback, Spanish practice with English explanations

Learner: "Ayer voy al mercado."

Partner: "¿Qué compraste?

Small correction: **Ayer fui al mercado.** Use _fui_ for this completed trip
yesterday."

The partner acknowledges the intended story, addresses one useful pattern, and
leaves a single question to answer. The example is not a required output format.

## At-the-end feedback

For that same learner sentence, respond to the story without interrupting with
grammar instruction. When asked to wrap up, include the original and corrected
phrase with a short explanation. Do not announce a new hidden-error count.

## Valid variation is not an error

"Vos tenés razón" is valid voseo in varieties that use it. Do not replace it
with "Tú tienes razón" as a grammatical correction. If the learner requests
practice in a different variety, describe the alternative as a variety choice.

Similarly, do not treat British "at the weekend" as an error because another
variety uses "on the weekend."

## Focused exercise

Ask for one past-tense sentence before showing its answer. If the learner gets
stuck, offer a clue. After explaining, use a different context on the retry.
Accept another grammatical sentence that satisfies the exercise.

## Honest recap

"You asked a clear follow-up question about the menu. One useful change:
_Ayer voy_ → _Ayer fui_ for that completed trip. Next time, tell a short story
about something you did yesterday."

Only say this when those events occurred in the conversation. If all the learner
did was select a language, there is no language-performance evidence to assess.
