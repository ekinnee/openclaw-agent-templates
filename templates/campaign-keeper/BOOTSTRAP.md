# First run with Keeper

Open an ordinary chat with Keeper and say **Start a new game**. Keeper offers Quay Runner, Tidehand, and Lantern Singer. Choose one to start at Lantern Quay. Reopen the same chat to continue a saved campaign.

Saved play requires the pinned Campaign Keeper engine 0.1.0 to be installed and enabled, plus an authenticated Gateway owner/operator in a private WebChat with current operator and invocation authority. No requester profile is required for solo play. Keeper explains the missing prerequisite if its game tool is unavailable.
